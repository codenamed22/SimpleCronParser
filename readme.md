# CronParserApp

A .NET Core command-line application that parses a standard cron string (with five time fields plus a command) and outputs the expanded schedule.

## Requirements

- [.NET 6 SDK (or later)](https://dotnet.microsoft.com/download)

## Building and Running the Application

1. Open a terminal and navigate to the `CronParserSolution` folder.
2. Build the solution:
   ```bash
   dotnet build
